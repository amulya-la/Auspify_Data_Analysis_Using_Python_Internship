# Auspify Data Analysis Internship - Netflix Dataset Analysis

## Overview
This repository contains the end-to-end data analysis project completed for the Auspify Data Analysis Internship using the official Netflix Movies and TV Shows dataset.

## Project Structure
- `Data/`: Contains raw (`Dataset internship.xlsx`) and processed (`cleaned_netflix_data.csv`) datasets.
- `Notebooks/`: Contains complete Python source notebooks (`task1_cleaning.ipynb` through `task6_business_report.ipynb`).
- `Screenshots/`: Contains execution proof screenshots for code and output verification across all tasks.
- `README.md`: Project summary and documentation.

## Tasks & Workflow
1. **Task 1: Data Cleaning & Preparation**
   - Handled missing values, formatted columns, removed duplicate entries, and exported clean data.
2. **Task 2: Content Type Analysis**
   - Evaluated catalog distribution between Movies and TV Shows.
3. **Task 3: Country-Wise Distribution Analysis**
   - Identified top content-producing nations globally.
4. **Task 4: Release Year Trends Analysis**
   - Analyzed content expansion trends from 1990 to present.
5. **Task 5: Genre & Rating Analysis**
   - Explored audience age ratings and dominant genre categories.
6. **Task 6: Advanced Strategic Business Report**
   - Generated key executive metrics, portfolio distribution ratios, and growth recommendations.
